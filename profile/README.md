# StackEnhance

Marketing tools for e-commerce teams, built in Sweden by Stack Enhance AB.

- **[Signal](https://stackenhance.com/signal)** captures and scores the marketing email your competitors send: send calendars, offers, subject lines and benchmarks, plus [public brand pages](https://stackenhance.com/brands).
- **[Studio](https://stackenhance.com/studio)** turns a product catalogue and brand kit into product feeds for Google, Meta and ChatGPT, and renders ads for every size and channel.

## Open source

**[signal-mcp](https://github.com/stackenhance/signal-mcp)** is Signal by StackEnhance as a free, read-only MCP server. Ask Claude, ChatGPT or Cursor how often e-commerce brands in the Nordics and Germany send marketing email.

```
https://mcp.stackenhance.com/mcp
```

No API key, no sign-in. Setup for every client is in the [README](https://github.com/stackenhance/signal-mcp#setup).
